Desarrollador UI

Se encarga de traducir diseños visuales en código funcional, con el fin de asegurarse de que la aplicación sea visualmente atractiva, intuitiva y ofresca una interacción impecable para el usuaio

Razones:

  1. Me gusta lo relacionado al diseño de interfaces
  2. Se pueden ver los resultados en tiempo real
  3. Cuenta con alta demanda y flexibilidad

Requisitos para ser Desarrollador UI son:

Requisito Objetivo principal Conocimientos
Dominio de funtamentos web Estructurar correctamente el contenido y darle estilo, asegurando que se adapte a cualquier tamaño de pantalla HTML 5 semántico, CSS3, Flexbox, CSS Grid y preprocesadores
Lógica e interactividad Dar vida a la interfaz, gestionar eventos del usuario y conectar la vista con los datos del servidor JavaScript moderno, manipulación del DOM, asincronía
Frameworks y librerías UI Construir interfaces complejas a través de componentes reutilizables, modulares y escalables React, Angular, herramientas de gestión de estado y librerías de estilos
Herramientas de prototipado Navegar por maquetas entregadas por el equipo de diseño para inspeccionar medidas, colores y exportar recursos gráficos Figma, Adobe XD, Sketch, Zeplin
